Jars used only to compile against and to start the IDE run configurations. They are never bundled into Fluid Compat,
and this folder is not part of any release.

- Flowing Fluids (Forge 1.20.1), REQUIRED to build. Keep the original file name (name-version.jar): the build derives
  the Gradle coordinate from it. Example: flowing_fluids-1.0.8-1.20.1-forge.jar
- YetAnotherConfigLib (Forge 1.20.1), needed to compile the settings screen. Example: YetAnotherConfigLib-3.6.6+1.20.1-forge.jar
